---
title: Quick start
description: Run the smallest complete example.
---

```typescript
import { convert } from 'libassimp';

import { readFile, writeFile } from 'node:fs/promises';

const bytes = new Uint8Array(await readFile('model.obj'));
const { files } = await convert({ name: 'model.obj', bytes }, { to: 'glb' });
await writeFile(files[0].name, files[0].bytes);
```

The first element of `files` is the primary output; a format that writes
sidecars, such as `gltf` with an external buffer, returns them after it.
