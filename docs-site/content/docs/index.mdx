libassimp converts 3D model files in Node.js, in the browser and in a worker.
It is the Open Asset Import Library compiled to WebAssembly behind a small
TypeScript API: hand it the bytes of a model, name the format you want back,
and it returns the converted bytes.

It is for the code that sits between a file and a viewer, a printer or a
kernel — an upload endpoint that normalises whatever a customer sends, a build
step that turns authoring files into GLB, a browser tool that writes 3MF for a
printer. It parses and writes files; it does not give you a scene graph.

importing the narrowest one that covers your conversion is the whole size

## The smallest example

```bash tab="npm"
npm install libassimp
```

```bash tab="pnpm"
pnpm add libassimp
```

<ConvertDemo>

```typescript
import { convert } from 'libassimp';

import { readFile, writeFile } from 'node:fs/promises';

const bytes = new Uint8Array(await readFile('cube.obj'));
const { files } = await convert({ name: 'cube.obj', bytes }, { to: 'glb' });

await writeFile(files[0].name, files[0].bytes);
console.log(files[0].name, files[0].bytes.byteLength);
```

</ConvertDemo>

The result is plain data: each file is a name and a copied `Uint8Array` that
belongs to you. Nothing is a handle, and nothing has to be freed.
