| Need                                              | Import               |
| ------------------------------------------------- | -------------------- |
| Any compiled input to `assjson`, `glb`, or `gltf` | `libassimp/importer` |
| glTF/USD-family input to any canonical output     | `libassimp/exporter` |
| Any compiled input to any canonical output        | `libassimp`          |

The full and exporter entries write exactly `3ds`, `3mf`, `assjson`, `dae`, `fbx`, `glb`, `gltf`, `obj`, `ply`, `step`, `stl`, `usda`, `usdz`, `x`, and `x3d`. The importer entry writes exactly `assjson`, `glb`, and `gltf`.

Binary/ASCII variants do not add rows: use `exportOptions.binary` for FBX, PLY, or STL. Use `exportOptions.materials: false` for OBJ without MTL. glTF 1 is not compiled; `glb` and `gltf` always mean glTF 2.

## Query edges without loading Wasm

```typescript
import { assimpCapabilities, conversionEdges } from 'libassimp/exporter';

const useful = conversionEdges.filter(({ from }) => from === 'glb');
for (const edge of useful) {
  console.log(edge.from, edge.to, assimpCapabilities.export[edge.to].extension);
}
```

`conversionEdges` contains exact valid import/export pairs minus identities. It has no MIME, schema, fidelity, native ID, or loader state; integrations attach their own policy metadata.

## Keep one instance warm

```typescript
import { createAssimp } from 'libassimp/exporter';

using assimp = await createAssimp();
console.log(assimp.formats.import, assimp.formats.export);
```

Instance format tables equal the generated static catalog. Each instance owns one module, heap, and FIFO queue; two entries or instances add their memory costs.
