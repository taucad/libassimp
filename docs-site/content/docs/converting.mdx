---
title: Converting
description: Understand the primary operation and output contract.
---

`convert` takes one file or an array whose first element is the entry file, and
one options object naming the target format. It resolves to a `ConvertResult`
whose `files` are plain copied byte arrays: nothing is a handle, and nothing
has to be freed.

Models that reference sidecar files — a material library, a texture, a USD
layer — either travel in the same array or arrive through the `resolve`
callback, which the importer calls synchronously by name.

`createAssimp` returns an instance when you want to control its lifetime.
The one-shot `convert` shares one lazily created instance per process.
